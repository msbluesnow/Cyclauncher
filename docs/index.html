Cyclauncher

A fast, open-source Android home screen launcher built with Jetpack Compose. Ergonomic one-handed navigation, tag folders, and deep theme customization.

Download APK View on GitHub
Beta v1.0.0-beta.3 (Build 22) — Core features are stable. Further refinements and new mechanics are actively in development. Feedback and bug reports are welcome.

Key Features

🔤

Versatile Search

Rectangular Alphabet Wheel with inertia physics, Side Alphabet Index strip, and instant text search.

🗂

Tag Folder System

Color-accented tag folders with 2x2 icon previews, 2D drag-to-reorder, and proximity-aware popup menus.

📌

Highlights & Widgets

Daily app install and update overview with full Android widget support — add, resize, reconfigure, remove.

🎨

Deep Theme Control

Echo Icon Theme palettes, Material You wallpaper colors, custom Color Picker, and adaptive text shadows.

🌐

Character Mapping

Bind Cyrillic, Arabic, emoji, and any symbol to search index buckets. Built-in presets included.

🤖

AI-Assisted Tagging

Batch-categorize apps via an Export → AI Prompt → Import workflow with full JSON backup.
