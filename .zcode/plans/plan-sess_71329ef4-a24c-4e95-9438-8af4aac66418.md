
## План: Автоматическое добавление тегов через нейросеть

### Общий workflow:
1. В настройках появляется кнопка **"Auto Tags"** (рядом с Labels Backup)
2. Нажатие открывает экран инструкций **AutoTagsScreen**
3. На экране 3 шага с кнопками + промпт для нейросети (с кнопкой копирования). Промпт содержит пример выходного JSON
4. После загрузки JSON — диалог подтверждения → применение тегов

### Формат JSON

**Экспорт** (что отправляется нейросети):
```json
[
  {"package": "com.android.chrome", "label": "Chrome"},
  {"package": "org.telegram.messenger", "label": "Telegram"},
  ...
]
```

**Импорт** (что нейросеть возвращает — пример встроен в промпт):
```json
[
  {"package": "com.android.chrome", "label": "Chrome", "tag": "Браузеры", "color": "#3B82F6"},
  {"package": "org.telegram.messenger", "label": "Telegram", "tag": "Мессенджеры", "color": "#10B981"},
  ...
]
```

### Промпт для нейросети (с примером):
Промпт содержит:
1. Инструкции: сгруппировать в 10-15 категорий, добавить поля `tag` и `color`, вернуть ТОЛЬКО JSON
2. **Пример выходного формата** с 5 приложениями (Chrome, Telegram, YouTube, Spotify, Chess):
```
Here is a JSON array of installed mobile apps.
Please categorize each app into a group and assign a color (hex format) to each group.

Requirements:
- Use minimal number of categories (10-15 groups)
- Group apps into meaningful, concise categories
- Assign each category a distinct color
- Add two new fields to each object: "tag" (category name) and "color" (hex color like "#3B82F6")
- Return ONLY the modified JSON array, no other text

Example of the expected output format:
[
  {"package": "com.android.chrome", "label": "Chrome", "tag": "Браузеры", "color": "#3B82F6"},
  {"package": "org.telegram.messenger", "label": "Telegram", "tag": "Мессенджеры", "color": "#10B981"},
  {"package": "com.google.youtube", "label": "YouTube", "tag": "Видео", "color": "#EF4444"},
  {"package": "com.spotify.music", "label": "Spotify", "tag": "Музыка", "color": "#1DB954"},
  {"package": "com.chess.app", "label": "Chess", "tag": "Игры", "color": "#8B5CF6"}
]

Here are my apps:
[apps JSON here]
```

### Изменения по файлам:

#### 1. `data/AppActionsManager.kt` — новые методы:
- **`exportAppNames(uri: Uri)`** — экспортирует список `{package, label}` всех установленных приложений в JSON файл
- **`parseAutoTags(uri: Uri): AutoTagsResult`** — парсит загруженный JSON с размеченными приложениями. Извлекает уникальные теги (name, color) и маппинг package → tagName
- **`applyAutoTags(preview: AutoTagsPreview)`** — создаёт теги (если ещё не существуют с таким именем), назначает теги приложениям по packageName. Сохраняет в SharedPreferences.

#### 2. `LauncherViewModel.kt` — новые методы и StateFlow:
- `autoTagsPreview: StateFlow<AutoTagsPreview?>` — состояние для диалога подтверждения
- **`exportAppNames(uri: Uri)`** — делегирует в AppActionsManager
- **`loadAutoTagsPreview(uri: Uri)`** — парсит JSON и устанавливает `autoTagsPreview`
- **`applyAutoTags()`** — применяет теги из preview, очищает preview
- **`dismissAutoTagsPreview()`** — сбрасывает preview без применения

#### 3. Новый файл: `ui/screens/AutoTagsScreen.kt`
Экран с инструкциями (стиль SettingsScreen):
- **Шаг 1**: "Экспортировать названия приложений" → кнопка вызывает `CreateDocument("application/json")` с именем "cyclauncher_apps.json" → `viewModel.exportAppNames(uri)`
- **Шаг 2**: Промпт для нейросети с примером + кнопка "Копировать" (копирует в буфер обмена). Промпт содержит пример из 5 приложений
- **Шаг 3**: "Загрузить размеченные приложения" → кнопка вызывает `GetContent("application/json")` → `viewModel.loadAutoTagsPreview(uri)`
- **Кнопка "Назад"** — возвращает к настройкам

#### 4. `ui/screens/SettingsScreen.kt` — изменения:
- Добавить состояние `var showAutoTagsScreen by remember { mutableStateOf(false) }`
- В Card настроек добавить строку **"Auto Tags:"** с кнопкой-иконкой `Icons.Outlined.AutoAwesome`
- При `showAutoTagsScreen == true` рендерить `AutoTagsScreen` вместо основного контента

#### 5. `MainActivity.kt` — изменения:
- Добавить диалог подтверждения применения авто-тегов (условный рендеринг при `autoTagsPreview != null`)
- AlertDialog показывает: количество новых тегов, количество затронутых приложений
- Кнопки "Применить" / "Отмена"

### Неизменные файлы:
- `model/Tag.kt` — используется как есть
- `model/AppInfo.kt` — не меняется
- Все UI components — не меняются
